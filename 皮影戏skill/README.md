# 皮影戏动画技能（shadow-puppet-animation）

一个给 Claude 用的技能：一句话描述想要的故事，就能用代码做出一部中国皮影戏风格的动画短片。画面、字幕和配乐全部由程序生成。

第一部成片是《灯影五千年》：3 分钟，14 幕，从炎黄一路讲到登月。

## 它能做出什么

| 产出 | 说明 |
| --- | --- |
| 逐镜头脚本 | Docs 文档，每个镜头写明时间、画面、“角色名 + 台词”的字幕和音效；每一幕单独写音乐（乐器、调式、速度、参考曲） |
| 风格样张 | 正式制作前先渲染 1–2 张画面给你确认 |
| 网页播放器 | 单个 HTML 页面，有播放/暂停、进度条、章节跳转、静音、全屏，配乐内嵌 |
| MP4 视频 | 1080p / 30fps 原片，外加一个 30 MB 以内的 720p 版本方便直接下载 |

## 画风

按真实皮影的样子来做，不是扁平的彩色插画：

- 以深色牛皮为底，红、绿、黄、蓝是半透明的染色块。
- 花纹是真正刻穿的孔，后面的幕光会透出来。
- 每块皮子的边缘都是“深色—透光细缝—深色”的阳刻双线。
- 人物修长，头身比约 1:9。脸部刻空，只留侧面轮廓线，配丹凤眼和柳叶眉。
- 每个人偶露出三根操纵签子（脖颈一根、两手各一根）。
- 背景是一块透光的橙黄纯色幕，楼阁、树、云、船等景片也是镂空皮子；远处的景片做虚化。

## 安装

1. 解压后得到 `shadow-puppet-animation/` 文件夹。
2. 把整个文件夹放进你的技能目录（或者在 Claude 的技能设置里上传这个压缩包）。
3. 保留 `references/` 目录，技能会在定画风时读取里面的参考图。

## 怎么用

直接跟 Claude 说想做什么，例如：

- “做一个皮影戏动画，讲中国五千年历史，三分钟”
- “用皮影戏的形式讲《西游记》三打白骨精，两分钟”
- “做一段皮影风格的春节短片”

Claude 会按下面的顺序推进，每一步都会停下来等你确认：

1. 写逐镜头脚本 → 你看过再改
2. 渲染风格样张 → 你确认明暗、刻工和眉眼
3. 制作全片画面和字幕，逐镜头检查人物有没有被建筑挡住
4. 用采样乐器编配、混音配乐
5. 发布网页播放器，导出并发送 MP4

想改的地方随时说，比如“再暗一点”“眼睛不够精致”“这里人被挡住了”“配乐不好听”。

## 运行环境

技能在 Claude 的云端工作区里运行，用到这些工具（缺的会自动安装）：

- Chromium + Playwright：逐帧渲染画面、截图检查、导出视频帧
- ffmpeg：解码音源、编码 MP4、压缩视频
- Python（numpy、scipy）：配乐的离线混音
- 网络能访问 GitHub：配乐所需的乐器采样从 GitHub 上的 MIDI.js 音源库下载

## 已知限制

- 单个文件超过 30 MB 发不出来，所以 1080p 原片（约 115 MB）需要另外压一个 720p 版本，或者切成几段发。
- 3 分钟成片导出约 5400 帧，在云端工作区大约需要 8 分钟，编码还要再等几分钟。
- 民族乐器用的是最接近的通用采样（例如用尺八代替箫、陶笛代替埙、三味线代替琵琶），音色和真实民乐有差距。
- 网页播放器在性能较弱的设备上可能掉帧，视频版不受影响。
